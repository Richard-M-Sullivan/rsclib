## build, run
These are scripts you can put on your path.
They give you access to the build and run command, which will search for a build.sh or run.sh file to execute.
It looks at your current position in file system and will keep traversing to each parent directory until it finds the file or hits the root direcory.
It is recommended to put the build.sh and run.sh files in the root of your project.
